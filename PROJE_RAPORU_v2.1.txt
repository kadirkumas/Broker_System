    - is_grid_position, grid_group_id, grid_level, grid_side
    - grid_entry_price, grid_tp_price, grid_created_at, grid_state
  • order_manager.py: open_grid_position() + close_grid_position()
  • position_manager.py: _check_grid_positions() + _execute_grid_close()
  • strategy_engine.py: DYNAMIC_GRID_REEL dispatch + symbol state cache
  • grid_state tablosu: backend tek doğru kaynak

  • index.html: Dynamic Grid REEL paneli (5. strateji)
  • chart.js: calcDynamicGridReel() + backend-driven (5 sn fetch)
  • Grafik etiketleri: L1..L10 (pembe), S1..S10 (sarı)
  • UNIQUE (symbol+group+level) duplicate koruması

Grid mantığı:
  • Referans etrafında N/2 SELL (üst) + N/2 BUY (alt)
  • BUY seviyesi TP = üstteki komşu seviye
  • SELL seviyesi TP = alttaki komşu seviye
  • Recenter: 24 saat VEYA range kırılımı

### 3.2 AI TTP (Kademeli Trailing Stop) ⭐⭐⭐
--------------------------------------------------------------------------------
Amaç     : Kâr arttıkça trail sıkılaşsın
Eski isim: "İzleyen Stop (%)"
Yeni isim: "🎯 AI TTP"

Kademeler (default):
  +1.5%  →  %0.30 trail  (aktivasyon - TP)
  +2.5%  →  %0.20
  +4.0%  →  %0.12
  +6.0%  →  %0.07
  +10.0% →  %0.03 (zirve, kâr kilitli)

Format: "1.5:0.3, 2.5:0.2, 4:0.12, 6:0.07, 10:0.03"
  • kâr%:trail% ikilisi
  • Ratchet mantığı (seviyeler geri dönmez)
  • Boş = trailing yok
  • Tek değer "0:0.3" = klasik davranış

Backend:
  • position_manager.py: _parse_trailing_steps() + _get_ai_ttp_pct()
  • backtest_engine.py: aynı mantık
  • Log: [AI-TTP] AKTİF / Kademe geçişi
  • Kapanış sebebi: "AI-TTP (2.35%)"

Frontend:
  • index.html: 4 stratejide text input + tooltip
  • chart.js: getStrategyBotConfig + backtest modal

### 3.3 Radar (Volatilite Filtresi) ⭐⭐
--------------------------------------------------------------------------------
Formül: A + B
  A = |24s değişim %|
  B = (High - Low) / Fiyat × 100
  Skor = A + B

Threshold: >= 10 (default)
Min 24s  : >= 2%
Sıralama : Skor DESC
Buton    : "🔥 Radar (194)" (sayaç)
Tooltip  : Formül açıklaması
Ayarlama : window._radarSetThreshold(n)
