  - Auth     : X-Sync-Token header
  - Token    : brk_tL63V_W9HXNZJu_pv8Qq7VifHR8eu10

READ-ONLY KİLİDİ (CLOUD):
  - Middleware : readonly_middleware
  - Kontrol    : IS_REPLICA + method POST/PUT/DELETE/PATCH
  - Muaf       : /api/sync/* (kendi token auth'u var)
  - Yanıt      : 403 {"status":"error","message":"Replica mode: read-only"}

AUTH (BASIC):
  - Local : Kapalı (test kolaylığı)
  - Cloud : Açık (admin / 9060Fk.1)
  - Bypass: /favicon.ico, /robots.txt, /api/sync/*

  - Hash   : SHA-256 (HTTPS/localhost) veya basit hash (HTTP+IP)
